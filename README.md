# RAG Assistant for Commerce Policies

Standalone repository split from `agentic-commerce-platform`.

## What This Demonstrates

Deterministic local retrieval over markdown commerce policies with citations and refusal behavior.

This is a demo/training project. It uses mock grocery data only. It does not use real Kroger APIs, real payment APIs, real customer data, or secrets.

## Setup

```bash
make setup
```

## Run

```bash
make run
```

## Verify

```bash
make test
```
